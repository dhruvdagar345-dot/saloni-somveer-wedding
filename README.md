# Saloni & Somveer — Wedding Invitation

A responsive, static wedding invitation website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload all files in this folder (keep `index.html`, `style.css`, `script.js` at the repository root).
3. In Vercel, choose **Add New → Project**, import the GitHub repository.
4. Framework Preset: **Other**. Build Command: leave blank. Output Directory: `.`.
5. Click **Deploy**. Vercel will provide a live URL.

## Optional wedding music
Add an MP3 you have permission to use as `assets/wedding.mp3`. The music button is user-activated (it will not autoplay).
